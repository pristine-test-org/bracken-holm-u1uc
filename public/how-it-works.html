How the list works

  1. Anyone on the team adds an item to the shared list.
  2. The landing page reads the five newest items each time it loads.
  3. Finished items are marked with a check so they are easy to spot.

Items usually show up within a few seconds of being added.

Back to the landing page

The list is shared across the whole team, so what you see on the landing page is what everyone else sees too, in the same order.
